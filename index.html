    Comment s'en servir

    Quatre gestes
    1. Choisissez Scalping, Day ou Swing. Le motif se lit sur M15, H1 ou H4.
    2. Une fiche Acheter ou Vendre est un sens autorisé, pas un ordre.
    3. Trait bleu = cou, trait ambre = second extrémum. Le W ou le M se juge à l'œil.
    4. Je prends note votre choix sur cet appareil. Rien n'est envoyé à un courtier.
    Pour que ça tourne sans cette page
    1. Téléphone, écran verrouillé : TradingView. Colle le script Pine du ZIP, ajoute-le au graphique, active l'alerte. C'est le serveur TradingView qui prévient, pas cette page.
    2. Zones et bandes T11 : MetaTrader 5. Copie le dossier MT5/MQL5 du ZIP, compile l'indicateur puis le robot, laisse-les sur le graphique.
    3. L'ordre : le mode d'origine ne l'envoie pas, même si TradeAuto est vrai. Tu le places chez le courtier. Laisse TradeAuto sur false.
    4. Pour que le terminal reste allumé quand l'ordinateur est éteint, il lui faut un VPS. Cette page ne devient pas le courtier.

    Le vocabulaire 4.42

    Jugement manuel
    Réglage d'origine activé. Un W absent, trop rapide ou non réintégré n'interdit plus le sens. Buffer +2 ou −2.
    Mode historique
    Le W/M redevient un veto. Buffer +1 ou −1, seulement si le motif passe les anciens critères et un rapport d'au moins 2.
    W et M
    Double creux pour acheter, double sommet pour vendre. Deux extrêmes proches, un cou entre les deux.
    Ce qui peut encore dire non
    Tendance locale absente, contexte opposé, mouvement flou, week-end sur le forex et l'or, prix illisibles.
    Zones, ordre et T11
    Ils vivent dans MetaTrader, pas dans cette page. En jugement manuel, l'expert 4.42 non plus n'envoie aucun ordre W/M et ne déplace pas T11. Les zones et les bandes T11 se dessinent sur le graphique du terminal. L'ordre, tu le passes toi-même avec les niveaux de la fiche.
